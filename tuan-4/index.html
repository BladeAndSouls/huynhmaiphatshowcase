1. Hệ Thống Biến CSS (:root)

Thay vì hard-code mã màu và khoảng cách trực tiếp vào từng thẻ, toàn bộ được quy chuẩn tại :root giúp quản lý tập trung và chuyển đổi Dark/Light mode mượt mà:

--primary-color

Màu xanh chủ đạo

--secondary-color

Màu đen/tối bổ trợ

--text-dark / --text-muted

3 mức xám cho text

--spacing-base (15px)

Khoảng cách chuẩn

Bài 1: Typography System

Responsive Typography Scale

Thiết lập hệ thống cỡ chữ sử dụng biến CSS (--fs-h1, --fs-h2, --fs-h3, --fs-body). Khi màn hình nhỏ hơn 600px, cỡ chữ tự động thu nhỏ lại để tránh tràn văn bản:

Heading 1: Tiêu Đề Cấp 1 (Tự động co giãn theo viewport)

Heading 2: Tiêu Đề Cấp 2 (Chuẩn tỷ lệ hiển thị di động)

Heading 3: Tiêu Đề Cấp 3 (Phân cấp rõ ràng, dễ đọc)

Đoạn văn bản mẫu (Body paragraph) sử dụng biến --fs-body và --text-muted. Khi bạn mở Chrome DevTools và chuyển sang màn hình điện thoại dưới 600px, toàn bộ các tiêu đề trên sẽ tự động giảm tỷ lệ mượt mà mà không gây vỡ layout.

Bài 6: Mobile-First Contact Form

Mobile-First Contact Form

Trên Mobile: các ô nhập liệu chiếm 100% chiều rộng. Trên Desktop: form được giới hạn chiều rộng max-width: 600px và căn giữa trang:

Quy Chuẩn Code Responsive

Tiêu Chuẩn "Code Tốt" vs "Code Rác" Trong Responsive Design

Bảng đối chiếu kiểm soát chất lượng mã nguồn CSS trong thiết kế Responsive:

Thành phần ✅ Code Tốt (Nên dùng) ❌ Code Rác (Nên sửa)
Chiều rộng width: 90%; hoặc max-width: 1200px; width: 1200px; (Cố định gây tràn viền)
Đơn vị Font rem hoặc em (ví dụ: 1.2rem) px (ví dụ: 20px) cứng cho mọi nơi
Chia cột display: grid; hoặc flex; float: left; hoặc display: table;
Căn lề margin: 0 auto; margin-left: 250px; (Cố định cứng)
